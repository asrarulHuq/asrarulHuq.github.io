## Zero-touch File Browser fork bootstrap

Run this one command to generate a ready-to-work File Browser fork workspace with deployment scaffolding:

```bash
GITHUB_USER=<your-user> FORK_REPO=<your-fork-repo-name> ./automation/bootstrap_filebrowser_fork.sh
```

What it creates automatically:
- implementation task plan for custom share slugs + lifetime links
- deployment override for Docker Compose
- deployment checklist
